# 微信小程序上线前检查清单

更新日期：2026-07-16

## 一键检查

在项目根目录运行：

```powershell
cd E:\SCTI_Study
node scripts\preflight-release.mjs
node scripts\validate-question-banks.mjs
node scripts\validate-mini-program.mjs
node --test miniprogram\tests\*.test.js
cd campus_persona
npm.cmd test
cd ..\frontend-demo
npm.cmd test
```

所有命令必须以退出码 0 结束。预检中的 `WARN` 是待办提示，`ERROR` 会阻断发布。

`node scripts\preflight-release.mjs` 用于本地开发验收；真正上传前必须再运行严格门禁：

```powershell
node scripts\preflight-release.mjs --release
```

严格门禁会把未配置 CloudBase、Git 工作树不干净/无远端以及上传边界问题升级为错误。当前在尚未配置云端和 GitHub CLI 的阶段，严格门禁失败属于预期。

## 已完成的仓库准备

- 原生小程序入口为 `miniprogram/`，AppID 保留在本机 `project.config.json`。
- 高中、大学、硕博三版本均有 20 道题和 16 个标签。
- Q1–Q19 每题四个选项；Q20 为独立自我认知题，不参与主标签和四维计算。
- 题目、文案、算法、版本、人物展示和分享文案均从配置或生成数据读取，页面不硬编码题目。
- 客户端公开题库不包含核心题、权重、目标向量或标签排名等私有评分数据。
- 本地模式与 CloudBase 模式严格分离；配置环境 ID 后不会回退到 localhost。
- 四个云函数源码已准备：`get-bank`、`submit-quiz`、`user-login`、`record-share`。
- 结果页人物区域按“版本 + 标签”配置，图片加载失败时自动显示统一占位。
- 分享海报公共数据模型已预留，后续可以接 Canvas 或服务端图片生成器。
- 当前主包约 0.63 MB，低于微信小程序 2 MB 主包边界。

## 本地开发验收

- 先在 `frontend-demo` 运行 `npm.cmd start`。
- `project.private.config.json` 的 `urlCheck=false` 只用于开发者工具访问本机服务。
- 在开发者工具中依次确认高中、大学、硕博均能进入题目。
- 首次答题时 Q1–Q19 点击选项自动进入下一题；返回复查后允许使用“下一题”。
- 首次回答 Q20 后自动计算并进入结果页；复查已回答的 Q20 时使用“查看结果”。
- 结果页应能上下滚动，并显示人物区、完整解读、四维度、Q20 自我认知、彩蛋和分享区。
- 欢迎页在较矮设备上应能上下滚动到“选择身份并开始”按钮。

## 当前非阻断素材待办

## 版本库与回滚

- 当前正式目录 `E:\SCTI_Study` 没有 `.git`，GitHub 的 `agent/upload-campus-persona-v5` 分支仍是较早版本。
- 发布远端更新前先安装并登录 GitHub CLI：`gh auth login`。
- 登录后应在独立克隆中审查完整差异、排除 `project.config.json`、`project.private.config.json`、密钥和本地缓存，再提交并推送。
- 不要直接把当前目录整体拖拽覆盖到 GitHub；必须保留可审查提交和回滚点。

## CloudBase 操作

以下内容需要真实云环境，参见 `campus_persona/docs/wechat-cloud-deployment.md`：

1. 创建或选择 CloudBase 环境。
2. 创建 `users`、`quiz_records`、`share_records` 集合和索引。
3. 仅在云函数环境变量中设置 `OPENID_HMAC_SECRET`。
4. 上传并部署四个云函数，选择云端安装依赖。
5. 把 `miniprogram/config/runtime.js` 的 `cloudEnvId` 填为真实环境 ID。
6. 真机验证三个版本的取题、提交、结果和分享记录。

## 需要人工完成的微信平台事项

- 小程序主体认证、服务类目、隐私保护指引和用户隐私授权说明。
- 体验版成员与真机验收。
- 版本号和上传备注确认。
- 微信审核提交、审核反馈处理和正式发布。

## 发布前最后一遍

1. 重新构建题库生成物，禁止手工修改生成文件。
2. 运行本页“一键检查”全部命令。
3. 确认 `cloudEnvId` 已填写且预检不再提示本地模式。
4. 检查客户端及日志不存在 AppSecret、openid、身份哈希、token、完整答案或其他凭据。
5. 使用体验版完整走通三版本，再提交审核。
